Install RietveldTV.

Ten minutes, over Wi-Fi, no root. Nothing is deleted: you can switch back to your old home screen at any time.

Time ~10 minDifficulty easyCost free

Before you start

Requirements

Tick these off first (click a line). If something is missing, the step that fixes it is linked.

  • An Android TV or Google TVAndroid 8.0 or newer (check: Settings → Device Preferences → About → Android TV OS version). Sony, Philips, TCL, Xiaomi, Chromecast with Google TV, NVIDIA Shield and most others work. Amazon Fire TV is not supported.
  • The TV remoteYou will use it for a few menu steps and to try the result.
  • A computer on the same Wi-Fi or network as the TVWindows, macOS or Linux. A phone is not enough.
  • ADB on the computerA small free tool from Google that talks to the TV. Step 4 shows how to get it.
  • The TV's IP addressSomething like 192.168.1.50. Step 3 shows where to find it.
  • The RietveldTV app file (APK)Step 5.
Your apps, accounts and settings stay as they are. RietveldTV only shows the apps you pick, so the TV's own recommendations and ads are no longer on the home screen. The TV itself is not modified beyond making this the default Home screen.

Step by step

Install

  1. Turn on Developer options on the TV

    On the TV: Settings → Device Preferences → About, scroll to Build (or "Android TV OS build") and press OK on it 7 times. A message says "You are now a developer".

    The menu names differ a little between brands. On Google TV it is Settings → System → About. Look for the word Build.

  2. Turn on debugging over the network

    Go back one level: Settings → Device Preferences → Developer options. Switch on USB debugging and, if you see it, Network debugging or Wireless debugging.

    If your TV shows Wireless debugging with a "Pair device with pairing code" button, note both the IP address and the port it shows (for example 192.168.1.50:37215). You will use ip:port instead of just the IP below. Details in Troubleshooting.

  3. Find the TV's IP address

    On the TV: Settings → Network & Internet, open your Wi-Fi network and look for IP address. Or look at the device list in your router's web page. Write it down.

  4. Install ADB on your computer

    Ubuntu / Debian:

    sudo apt install android-tools-adb

    Fedora: sudo dnf install android-tools. Arch: sudo pacman -S android-tools.

    With Homebrew:

    brew install android-platform-tools

    Download SDK Platform-Tools for Windows (a zip file), unzip it, for example to C:\platform-tools. Then open that folder, click in the address bar, type powershell and press Enter. Use .\adb.exe wherever this page says adb.

    Check that it works: adb version should print a version number.

  5. Download RietveldTV

    Download RietveldTV.apkDownload scripts (zip)

    Save the APK in a folder you can find again, for example your Downloads folder.

    No download on the Releases page yet? Build it yourself: install JDK 17 and the Android SDK, then run ./gradlew assembleDebug. The file ends up in app/build/outputs/apk/debug/app-debug.apk. See the README.

  6. Connect to the TV and install

    Open a terminal in the folder with the APK. Replace 192.168.1.50 with your TV's IP (add :port if your TV showed one).

    Connect:

    adb connect 192.168.1.50:5555

    Now look at the TV: it asks "Allow USB debugging?". Tick Always allow from this computer and choose OK. Then check:

    adb devices

    Your TV should be listed as device (not unauthorized or offline).

    Install the app and make it the home screen:

    adb install -r RietveldTV.apk
adb shell cmd package set-home-activity --user 0 dev.oliver.home/.HomeActivity
adb shell input keyevent KEYCODE_HOME

    On macOS or Linux you can do the same in one go with the script from the zip:

    scripts/install.sh 192.168.1.50 RietveldTV.apk

  7. Press Home on the remote

    You should see the black screen with the spotlight. Use the arrow keys to move between apps and OK to open one. To add widgets (clock, time zones, weather), focus the + Widgets tile and press OK.

    If Home still opens the old launcher, go to Troubleshooting. It is a known quirk on some TVs, and it has a fix.

When something does not work

Troubleshooting

adb connect says "failed to connect" or "connection refused"

Check that the TV and the computer are on the same network (not a guest network), that debugging is on in step 2, and that the IP address is right. Some TVs switch debugging off after a restart: turn it on again. Newer TVs with Wireless debugging need pairing first: tap "Pair device with pairing code", then run adb pair IP:PAIRING-PORT and enter the code, then adb connect IP:PORT using the port shown on the main Wireless debugging screen.

adb devices shows "unauthorized"

The TV is waiting for you to accept the prompt. Look at the screen and choose OK. If no prompt appears: in Developer options use "Revoke USB debugging authorizations", then adb kill-server and connect again.

Home still opens the old launcher

Some TVs rank their own launcher or setup wizard higher. First pin ours (step 6 already did). If it still opens the old one, find what competes:

adb shell pm query-activities --brief -a android.intent.action.MAIN -c android.intent.category.HOME

and disable the package that is not dev.oliver.home (this is reversible):

adb shell pm disable-user --user 0 PACKAGE.NAME

Only do this for packages you recognise as launchers. On a Xiaomi TV this was needed for com.google.android.apps.tv.launcherx, com.mitv.tvhome.atv and the setup wizard com.google.android.tungsten.setupwraith. Disabling system packages can switch debugging off, so re-enable it afterwards.

Some of my apps are missing

RietveldTV shows only the apps in its list. Edit the list on the TV (+ Widgets is for widgets; apps are in config.json, see the README) and use the app's package name. Find it with adb shell pm list packages | grep -i name.

I want my old home screen back

On macOS / Linux: scripts/restore.sh 192.168.1.50. By hand:

adb shell pm enable com.google.android.apps.tv.launcherx
adb uninstall dev.oliver.home

Re-enable anything else you disabled with adb shell pm enable PACKAGE.NAME.
